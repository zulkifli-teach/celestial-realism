# Surface maps
- Earth: NASA Blue Marble, land_ocean_ice_2048; https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg
- Moon: NASA SVS CGI Moon Kit, LROC equirectangular 2K; https://svs.gsfc.nasa.gov/4720/
- Venus (radar surface), Mars, Jupiter, Saturn, Neptune: NASA 3D Resources image and texture collection. https://github.com/nasa/NASA-3D-Resources — collection README explicitly states assets are free and without copyright.
- Clouds: https://github.com/matteason/live-cloud-maps/ — CC0. Downloaded snapshot, not a live cloud feed.
- Mercury, Uranus, Sun: generated equirectangular surface illustrations, not NASA observation data.
- Venus's orange radar surface is a false-color surface visualization, not its cloud-covered visible-light appearance.
- Educational object sizes and orbital distances are deliberately compressed; orbital eccentricities, inclinations, and relative periods use astronomical values, not a current ephemeris.
